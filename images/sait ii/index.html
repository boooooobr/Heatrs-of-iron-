Чему вы научитесь

Frontend-разработка

  • Вёрстка сайтов на HTML5 и CSS3
  • Адаптивная графика и Flexbox/Grid
  • Язык программирования JavaScript (ES6+)
  • Разработка интерфейсов на React.js

Backend-разработка

  • Создание серверной логики на Node.js
  • Работа с базами данных (MongoDB, PostgreSQL)
  • Проектирование и разработка REST API
  • Безопасность и авторизация пользователей

Профессиональные навыки

  • Командная работа в Git и GitHub
  • Развёртывание проектов на хостинг (Deploy)
  • Методологии Scrum и Kanban
  • Подготовка к техническим собеседованиям

Что будет на проекте

Обучение в Wedstart построено вокруг создания полноценного выпускного проекта. Это не просто учебные задачи, а реальный веб-сервис, написанный вами с нуля.

В процессе работы вы:

— Пройдёте все этапы разработки: от проектирования базы данных до запуска на живом сервере.

— Научитесь связывать фронтенд-интерфейс с бэкенд-архитектурой.

— Добавите в портфолио рабочий кейс, который не стыдно показать будущему работодателю.
